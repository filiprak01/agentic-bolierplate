Docker

Background Runtime Today

Available now

  • Dockerfile builds the Python package.
  • docker-compose.yml starts API, role workers, PostgreSQL, and Redis.
  • ./data:/workspace/data preserves worker state.

Still required

  • Live Codex execution still runs through host-side control.
  • Future long-running queue workers can build on the dry-run loop.
  • Per-role logs and graceful stop/resume handling.

Codex

Subscription-Aware Execution

Routing

Architecture and final audits use stronger reasoning. Development, review, testing, docs, and release tasks use role defaults to protect quota.

Limits

Workers persist failed request, partial output, logs, and assignment state before pausing on low or exhausted limits.

Create A New Project

Recommended First Run

  1. Configure GitHub, Jira, Confluence, AgileTest, Codex, durable paths, and target project path.
  2. Create product vision, architecture, NFR, and release-scope docs.
  3. Generate or draft backlog candidates into Jira FUNNEL.
  4. Move approved work to READY TO START.
  5. Run scheduler/release-manager selection and context pack generation.
  6. Execute development, review, testing, regression, retro, and PO acceptance.
